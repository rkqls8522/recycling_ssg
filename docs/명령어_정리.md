## 1. 최종 학습 — 지금 돌려야 할 것

```bash
uv run --no-sync python ai/notebooks/07_final_training.py --log train_newsaug.log
```

| 조각 | 의미 |
| --- | --- |
| `uv run` | `pyproject.toml` 이 정의한 환경(`.venv`)으로 실행합니다. `.venv/Scripts/python.exe` 를 직접 쓰는 것과 같은 결과인데, uv 가 경로를 알아서 잡아 줍니다. |
| `--no-sync` | **환경을 건드리지 말고 그냥 실행**하라는 뜻입니다. 이게 없으면 uv 가 `uv.lock` 기준으로 환경을 맞추면서 `defusedxml` · `python-pptx` · `xlsxwriter` 3개를 지웁니다(수동 설치분이라 락파일에 없음). 학습과는 무관하니 지워져도 되면 빼셔도 됩니다. |
| `--log train_newsaug.log` | 화면 출력을 그대로 파일에도 UTF-8 로 기록합니다. **파이썬이 직접 쓰기 때문에** 셸 인코딩 설정과 무관합니다. |

**소요 시간 약 22시간.** 20 epoch, 144,315장.

### 셸 파이프(`| tee`)를 쓰지 않는 이유

예전에 이렇게 안내드렸다가 문제가 생겼습니다.

```bash
# 쓰지 마세요
python ... 2>&1 | tee train.log
```

PowerShell 이 파이프 중간에서 UTF-8 바이트를 cp949 로 잘못 읽어 **한글이 깨진 채 파일에 저장**됐습니다(`07. 理쒖쥌 ?숈뒿`). `--log` 는 파이썬이 직접 쓰므로 이 문제가 없습니다.

참고로 `2>&1` 는 "에러 출력(2번)을 일반 출력(1번)에 합쳐라"는 뜻입니다. 파이프는 기본적으로 1번만 넘기므로, 합치지 않으면 에러가 로그에 안 남습니다. 지금은 `--log` 를 쓰므로 필요 없습니다.

## 3. 중간에 멈췄을 때 — 마무리만 수행

`best.pt` 는 매 epoch 자동 갱신되므로(val mAP50-95 가 기록을 경신할 때만 저장),
몇 epoch 에서 멈추든 그때까지 최고 가중치가 남아 있습니다.
다만 스크립트를 중단하면 평가·리포트 단계가 실행되지 않습니다.

```bash
uv run --no-sync python ai/notebooks/07_finalize.py
```

가장 최근 `best.pt` 를 찾아 검증 세트로 평가하고, 클래스별 성능 CSV·그래프·요약을
저장합니다. **이 단계에서는 `weights/best.pt` 를 건드리지 않습니다.**

```bash
uv run --no-sync python ai/notebooks/07_finalize.py --deploy
```

결과를 확인한 뒤 서비스용 `weights/best.pt` 를 교체합니다.
기존 파일은 `best.pt.backup_<날짜시각>` 으로 백업됩니다.

```bash
uv run --no-sync python ai/notebooks/07_finalize.py --weights <best.pt 경로>
```

특정 가중치를 지정해 평가합니다. 1차/2차 모델을 각각 재평가할 때 씁니다.

## 6. VSCode 웹뷰 문제 (이미 조치 완료)

노트북이 `Could not register service worker` 로 안 열릴 때 씁니다.
**VSCode 를 완전히 종료한 뒤** 실행합니다.

```bash
rm -rf "$APPDATA/Code/Service Worker" "$APPDATA/Code/Code Cache" "$APPDATA/Code/GPUCache"
```

캐시만 지우므로 설정·확장·열린 탭은 유지됩니다. 재시작 시 자동 생성됩니다.

그래도 안 되면 워크스페이스 편집기 상태를 초기화합니다.

```bash
rm -f "$APPDATA/Code/User/workspaceStorage/c520944cdbde4b283e319b4112c07f79/state.vscdb"
```

GPU 가속이 문제일 때는 이렇게 실행합니다.

```bash
code --disable-gpu "C:/AIchallengers/recycling_ssg_project/recycling_ssg"
```
