## 2. 문제 정의

생활폐기물 분리배출은 지자체별로 품목 분류·배출 요일·배출 방법이 제각각이라, 일반 사용자가
"이게 정확히 몇 번 분류인지", "우리 동네는 무슨 요일에 버려야 하는지", "이 규정에 예외가 있는지"를
매번 검색해서 확인해야 하는 번거로움이 있습니다. 특히:

- 폐기물의 정확한 분류명(대분류/소분류)을 알기 어렵다 — 육안으로는 재활용 여부가 헷갈리는
  품목(비닐 코팅 종이, 복합 재질 등)이 많다.
- 지자체별 배출 규정이 다르다 — 특히 경기도는 시·군별 예외 규정이 존재해 전국 공통 안내만으로는
  부족하다.
- 첫 안내가 틀렸을 때 사용자가 스스로 정정하거나 추가로 확인할 방법이 마땅치 않다.

## 3. 프로젝트 목표

1. **사진 한 장으로 분류** — YOLO 기반 Vision AI가 이미지 속 메인 객체를 탐지해 17종 폐기물
   분류 중 하나로 분류하고, Top-K 후보까지 함께 제시한다.
2. **지역 기준 배출 안내** — 사용자가 선택한 지역(서울 25개 자치구 + 경기 31개 시·군) 기준으로
   배출 요일과 배출 방법을 안내한다.
3. **틀렸을 때의 보정 경로 제공** — AI 예측이 틀렸을 때 후보 목록에서 직접 고르거나, 후보에도
   없으면 Gemini 기반 재분석(RAG 재분류 그래프)을 요청할 수 있다.
4. **후속 질문 대응** — 분석 결과에 대해 추가로 궁금한 점을 AI Agent에게 자연어로 물어볼 수 있다.
5. **재학습 데이터 축적** — 사용자 피드백(정정/확인)을 구조화된 형태로 쌓아, 향후 모델 재학습에
   활용할 수 있는 기반을 마련한다.

## 4. 프로젝트 범위

### 4.1 포함 범위 (In Scope)

- 회원가입/로그인(JWT 인증), 지역 선택
- 이미지 업로드 → Vision AI 분류 → 지역별 배출 정보 안내
- 사용자 피드백 3종(확인/후보 재선택/재분석 요청)
- AI Agent 기반 후속 질문 응답(RAG 기반 배출 규정 조회 포함)
- 즐겨찾기(자주 찾는 분류 저장)
- 서울특별시(25개 자치구), 경기도(31개 시·군) — 총 56개 지역 지원
- 재활용 폐기물 17개 분류(대분류 12종)

### 4.2 제외 범위 (Out of Scope)

- 서울/경기 외 타 지역 지원
- 재활용 불가 품목(일반쓰레기/음식물쓰레기 등 비재활용 폐기물) 분류
- 회원 간 소셜 기능(공유, 랭킹 등)
- 채팅 이력 저장 및 재조회(현재 설계상 Stateless)
- 컨테이너화/CI-CD 등 배포 자동화(현재 수동 배포 절차 — [deployment/](../deployment/) 참고)

## 5. 핵심 사용자 가치

| 사용자 관점 | 제공 가치 |
|---|---|
| "이게 뭔지 모르겠어요" | 사진만 찍으면 AI가 분류하고, 후보까지 보여줘서 스스로도 확인 가능 |
| "우리 동네는 언제 버려요?" | 로그인 시 선택한 지역 기준으로 배출 요일/방법을 즉시 안내 |
| "AI가 틀린 것 같아요" | 후보 재선택 또는 재분석 요청으로 스스로 정정 가능 |
| "이거 이렇게 버려도 되나요?" | AI Agent에게 자연어로 추가 질문 가능 |

## 6. 기술 스택 요약

| 영역 | 스택 |
|---|---|
| Backend | Python 3.13, FastAPI, SQLAlchemy 2.0, Pydantic v2, MySQL(Railway) |
| Vision AI | Ultralytics YOLO(yolo26n 기반 파인튜닝), PyTorch |
| AI Agent / RAG | LangGraph, Pinecone(벡터DB), Upstage Embeddings, Google Gemini |

| 인프라 | AWS S3(이미지 저장), 행정안전부 공공데이터 API(배출정보) |
| 패키지 관리 | uv(Python workspace), npm(Frontend) |
